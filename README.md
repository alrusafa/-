# المركز العراقي لحرية الإعلام

موقع عربي باتجاه RTL، جاهز للنشر على GitHub Pages.

## الملفات
- `index.html`: الموقع كاملاً (التصميم والتنسيقات والبرمجة والشعار المضمّن).

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع ملف `index.html` إلى المجلد الرئيسي للمستودع.
3. افتح Settings ثم Pages.
4. ضمن Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط Save.
6. انتظر اكتمال النشر وافتح الرابط الذي يظهر في صفحة Pages.
